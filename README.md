# Я Спартанец — мобильный прототип (v0.1)

Стартовый проект для Codex, Expo / React Native, Android и iOS. Дизайн: чёрный и золотой, вдохновлён афишей клуба. Интерфейс на русском.

## Запуск

1. Установить Node.js 20+.
2. В папке проекта выполнить `npm install`.
3. Выполнить `npx expo start`.
4. На Android/iPhone открыть QR-код через **Expo Go** (на iOS возможности Expo Go могут зависеть от версии SDK и доступного клиента). Альтернативно собрать development build.

Для Codex: откройте распакованную папку как проект. Сначала попросите Codex установить зависимости, проверить TypeScript и запустить Expo.

## Уже есть

- Регистрация игрока (имя + email), статус «ожидает подтверждения» и **кнопка демонстрационного подтверждения**.
- Домашний экран в чёрно-золотом оформлении, навигация, задачи, профиль.
- Все 16 занятий из загруженного PDF: название, неделя, цель, список кодов упражнений.
- Исходный 55-страничный PDF в `assets/` с оригинальными схемами, подробными карточками и таймингом.
- Локальное сохранение отметок в AsyncStorage.
- Черновая PostgreSQL-схема для будущей серверной части в `backend/schema.sql`.

## ВАЖНО: прототип, НЕ рабочая регистрация

Сейчас регистрация, подтверждение и прохождение занятий полностью локальные, для просмотра UX. **Нет сервера, входа по паролю/OTP, реального одобрения тренером или защищённого разграничения доступа.** Демо-кнопка подтверждения доступна самому пользователю и должна быть УДАЛЕНА до реального запуска. Не собирать и не загружать реальные личные данные игроков, пока не настроены серверная аутентификация, разрешения, хранение и согласия.

## Приоритет следующего шага для Codex

1. Поднять серверную авторизацию, например Supabase Auth/Postgres либо свой API.
2. Сделать `pending` по умолчанию и отдельный закрытый кабинет одобрения для тренера, проверяемый на сервере.
3. Запретить чтение и изменение чужих профилей без разрешения, включить RLS/эквивалентные проверки.
4. Импортировать занятия из `src/data/sessions.json`; создать карточки 34 упражнений и связать со схемами PDF.
5. Реализовать утверждаемую тренером посещаемость, нормативы и историю проверок.
6. Только после этого подключить push-уведомления, командные чаты, платежи и CRM.

## Важные условия курса

Бесконтактный курс для взрослых 18+, 8 недель, 2 занятия по 90 минут в неделю. Завершение курса не означает допуск к контактным упражнениям — решение принимает тренер на отдельном этапе.

## Проверки проекта

```sh
npx tsc --noEmit
python3 tests/check_sessions.py
CI=1 EXPO_OFFLINE=1 npx expo export --platform android --output-dir dist/android
```

Для сверки с PDF нужен `pdftotext` из Poppler. Данные в `src/data/sessions.json`
дословно перенесены из планов занятий на страницах 4–19
[`assets/American_Football_8_Weeks.pdf`](assets/American_Football_8_Weeks.pdf):
названия, недели, цели и коды упражнений в порядке плана, без повторов кодов.
Полные дозировки, тайминг и схемы остаются в PDF.

Проверено при исправлении первоначальной настройки: TypeScript без ошибок,
Android Expo export с Hermes и PDF, регистрация с валидацией, демо-подтверждение,
главная страница, все 16 занятий и сохранение прогресса после перезагрузки.
Интерфейс проверен в Chromium. Проверка не заменяет запуск на телефоне.
`expo export --platform android` создаёт пакет приложения для Android,
но не устанавливаемый APK/AAB; нативная сборка и запуск на устройстве не проверены.

## Демонстрационная веб-версия на GitHub Pages

Адрес после успешной публикации: https://722270a-svg.github.io/ya-spartanets/

В GitHub откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
Workflow `.github/workflows/deploy.yml` собирает сайт при push в `main` и при ручном
запуске через **Actions → Deploy demo to GitHub Pages → Run workflow**.
Pull Request выполняет сборку без публикации. В workflow используется только
штатный `GITHUB_TOKEN` с минимальными разрешениями; отдельные секреты не нужны.
Если GitHub попросит одобрить deployment окружения `github-pages`, подтвердите
его в Actions. Для бесплатного GitHub Pages обычно нужен публичный репозиторий.

Локальная воспроизводимая сборка (Node.js 22):

```sh
npm ci
npm run typecheck
npm run build:web
python3 tests/check_web_build.py
```

Веб-зависимости включены в package.json и package-lock.json. Базовый путь
`/ya-spartanets` задаётся в `expo.experiments.baseUrl` и применяется Expo к ресурсам.
Сайт — статическое приложение с переключением экранов внутри одной страницы;
сервер авторизации и перенаправления маршрутов не требуются.

Публикуется только `dist/web`: HTML, JS и учебный PDF. Исходники, `.env`,
локальное хранилище браузера и служебные файлы в артефакт не входят.
Тест проверяет список файлов, ссылки на ресурсы и распространённые сигнатуры
ключей; это не универсальный аудит секретов. PDF и данные курса будут публичны.
В проверенном PDF нет заполненных персональных анкет — только учебный материал
и пустой шаблон наблюдений. Регистрация работает локально, настоящих аккаунтов
не создаёт; используйте вымышленные имя и email. Прогресс остаётся в этом браузере
на этом домене и не переносится с localhost или Vercel.

Проверено перед публикацией: TypeScript, совместимость зависимостей Expo,
сборка для базового пути Pages, загрузка JS и PDF, регистрация и демо-подтверждение,
главная страница, все 16 занятий, сохранение аккаунта и прогресса после перезагрузки.
Во время браузерной проверки не было запросов к внешним серверам или ошибок JS.
Дизайн и данные тренировок сохранены.
