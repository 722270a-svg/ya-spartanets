# Я Спартанец — мобильный прототип (v0.1)

Стартовый проект для Codex, Expo / React Native, Android и iOS. Дизайн: чёрный и золотой, вдохновлён афишей клуба. Интерфейс на русском.

## Запуск

1. Установить Node.js 20+.
2. В папке проекта выполнить `npm install`.
3. Выполнить `npx expo start`.
4. На Android/iPhone открыть QR-код через **Expo Go** (на iOS возможности Expo Go могут зависеть от версии SDK и доступного клиента). Альтернативно собрать development build.

Для Codex: откройте распакованную папку как проект. Сначала попросите Codex установить зависимости, проверить TypeScript и запустить Expo.

## Уже есть

- Регистрация игрока (имя + email), статус «ожидает подтверждения» и **кнопка демонстрационного подтверждения**.
- Домашний экран в чёрно-золотом оформлении, навигация, задачи, профиль.
- Все 16 занятий из загруженного PDF: название, неделя, цель, список кодов упражнений.
- Исходный 55-страничный PDF в `assets/` с оригинальными схемами, подробными карточками и таймингом.
- Локальное сохранение отметок в AsyncStorage.
- Черновая PostgreSQL-схема для будущей серверной части в `backend/schema.sql`.

## ВАЖНО: прототип, НЕ рабочая регистрация

Сейчас регистрация, подтверждение и прохождение занятий полностью локальные, для просмотра UX. **Нет сервера, входа по паролю/OTP, реального одобрения тренером или защищённого разграничения доступа.** Демо-кнопка подтверждения доступна самому пользователю и должна быть УДАЛЕНА до реального запуска. Не собирать и не загружать реальные личные данные игроков, пока не настроены серверная аутентификация, разрешения, хранение и согласия.

## Приоритет следующего шага для Codex

1. Поднять серверную авторизацию, например Supabase Auth/Postgres либо свой API.
2. Сделать `pending` по умолчанию и отдельный закрытый кабинет одобрения для тренера, проверяемый на сервере.
3. Запретить чтение и изменение чужих профилей без разрешения, включить RLS/эквивалентные проверки.
4. Импортировать занятия из `src/data/sessions.json`; создать карточки 34 упражнений и связать со схемами PDF.
5. Реализовать утверждаемую тренером посещаемость, нормативы и историю проверок.
6. Только после этого подключить push-уведомления, командные чаты, платежи и CRM.

## Важные условия курса

Бесконтактный курс для взрослых 18+, 8 недель, 2 занятия по 90 минут в неделю. Завершение курса не означает допуск к контактным упражнениям — решение принимает тренер на отдельном этапе.
